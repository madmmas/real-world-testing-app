# Accessibility — Admin console and shop tools

- **A11Y-ADM-01** Sign in, dashboard, users, stores, books, orders: no critical axe violations.
- **A11Y-ADM-01a** Admin sign-in captcha is keyboard reachable in interactive mode (same widget as public).
- **A11Y-ADM-02** Section nav indicates current page; unavailable sections are not focusable dead ends.
- **A11Y-ADM-03** Tables (users, orders, books) have headers; row actions named for screen readers.
- **A11Y-ADM-04** Role-change controls are labeled; confirmation of dangerous role edits if present.
- **A11Y-SHOP-01** Inventory and store forms: labels, required fields, keyboard submit.
- **A11Y-SHOP-02** One-time API key plaintext is selectable/copyable and not only in a color flash.
- **A11Y-SHOP-03** Shop-role warning for buyers is readable by AT (not icon-only).
